# Консольный калькулятор

## Назначение
Программа выполняет простые арифметические действия с двумя числами.

## Какие задачи решает
- Сложение (+), вычитание (-), умножение (*), деление (/).
- Целочисленное деление (//), остаток от деления (%).
- Возведение в степень (^).
- Обрабатывает деление на ноль.
- Обрабатывает неизвестную операцию.

## Как запустить
1. Установи Python 3.
2. Сохрани файл `пр1(1).py`.
3. Открой терминал в папке с файлом.
4. Выполни команду:
   python пр1(1).py

# Расчёт стоимости покупки

## Назначение
Программа рассчитывает итоговую стоимость покупки с учётом скидки.

## Какие задачи решает
- Запрашивает название товара, цену и количество.
- Вычисляет общую стоимость.
- Применяет скидку:
  - от 5000 до 9999 — 5%
  - от 10000 до 14999 — 10%
  - от 15000 — 15%
- Выводит исходную стоимость, размер скидки в процентах и рублях, итоговую цену.
- Обрабатывает неверный ввод цены или количества.

## Как запустить
1. Установи Python 3.
2. Сохрани файл `Пр1(4).py`.
3. Открой терминал в папке с файлом.
4. Выполни команду:
   python Пр1(4).py
